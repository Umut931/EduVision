📊 Capteurs EduVision

Guide de démarrage rapide

🎯 Aperçu

Le module capteurs EduVision vous permet de lire et afficher les données de capteurs physiques (Raspberry Pi + Grove) en temps réel. Le système marche avec ou sans capteurs grâce au fallback automatique.

✓ Installation complète! Les capteurs sont prêts à l'emploi.

🚀 Démarrage Rapide (3 étapes)

1Démarrer le serveur 
npm start

ou avec nodemon pour le hot-reload:

npm run dev
2Accéder au dashboard

Ouvrez dans votre navigateur:

http://localhost:3000/sensors-dashboard.html

Vous verrez le tableau de bord avec les 4 capteurs.

3Activer le flux temps réel

Cliquez sur le bouton "📡 Activer flux temps réel" du dashboard.

Les données s'affichent maintenant en direct toutes les secondes!

🔌 Capteurs Disponibles

🌡️ Température

Type: BME280 (I2C)

Plage: -40°C à +85°C

Fallback: 20-25°C simulée

💧 Humidité

Type: BME280 (I2C)

Plage: 0% à 100%

Fallback: 50-65% simulée

💨 Qualité de l'air

Type: ADC ADS1115 (I2C)

Plage: 0-1000 ppm

Fallback: 300-500 ppm simulée

🚀 Mouvement

Type: PIR Sensor (GPIO17)

Plage: 0 (inactif) ou 1 (détecté)

Fallback: 0 (inactif)

📡 API REST

GET /api/sensors

Récupère les données actuelles des capteurs (une seule fois)

Exemple:

curl http://localhost:3000/api/sensors

Réponse:

{
  "success": true,
  "data": {
    "temperature": 22.45,
    "humidity": 52.30,
    "air_quality": 425,
    "motion": 0,
    "timestamp": 1710000000000
  }
}

Activer/Désactiver le flux WebSocket

POST /api/sensors/subscribe

Active l'envoi des données toutes les secondes

POST /api/sensors/unsubscribe

Désactive l'envoi des données

🔌 WebSocket (Socket.IO)

Recevez les données des capteurs en temps réel:

const socket = io('http://localhost:3000');

socket.on('sensor_data', (data) => {
    console.log('Température:', data.temperature);
    console.log('Humidité:', data.humidity);
    console.log('Qualité air:', data.air_quality);
    console.log('Mouvement:', data.motion);
});

💻 Intégration dans votre code

Option 1: Fetch (React, Angular, Vue)

const response = await fetch('/api/sensors');
const result = await response.json();
const { temperature, humidity } = result.data;

Option 2: Socket.IO (Temps réel)

const socket = io();
socket.on('sensor_data', (data) => {
    // Mettre à jour l'interface
});

Option 3: Node.js (Backend)

const sensors = require('./services/sensors');
const data = await sensors.readAllSensors();
console.log(data);

📦 Format des Données

Champ Type Unité Exemple
temperature number °C 22.45
humidity number % 52.30
air_quality number ppm 425
motion 0 ou 1 boolean 0 (inactif)
timestamp number ms 1710000000000

🧪 Tests

Tester l'API REST

curl http://localhost:3000/api/sensors | jq

Vérifier les capteurs I2C

i2cdetect -y 1

Valeurs attendues:

  • 48 = ADS1115 (qualité air)
  • 76 = BME280 (température/humidité)

Vérifier les logs

tail -f logs/$(date +%Y-%m-%d).log

⚠️ Troubleshooting

❓ Les données affichent NaN ou --

C'est normal! Les capteurs ne sont probablement pas branchés. Le système utilise automatiquement des valeurs simulées. Vérifiez les logs: tail -f logs/$(date +%Y-%m-%d).log

❓ "Port 3000 déjà utilisé"

Tuer le processus: lsof -i :3000 | grep LISTEN | awk '{print $2}' | xargs kill -9

❓ Socket.IO ne fonctionne pas

Vérifier les logs du serveur et la connexion au port 3000. Vérifier que les modules sont installés: npm install

❓ Le dashboard ne s'affiche pas

Vérifier l'URL: http://localhost:3000/sensors-dashboard.html Vérifier la console du navigateur (F12) pour les erreurs
